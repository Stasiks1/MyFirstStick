# MyFirstStick

Interactive bidirectional counter firmware for **M5StickC PLUS** (ESP32).

## Features
- Hardware button event handling (`M5.BtnA` & `M5.BtnB`).
- Clamped non-negative counter logic using `max()`.
- Modular screen rendering architecture in C++.

## Controls
- **Button A (Front):** Increment counter (+1)
- **Button B (Side):** Decrement counter (-1, min 0)
